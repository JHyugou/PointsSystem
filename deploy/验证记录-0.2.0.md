# 0.2.0 验证记录

日期：2026-10-11。

- 后端：18 项测试，17 项通过，1 项外部 SMTP 测试因未设置测试环境参数而跳过。注册、权限、积分、作业和兑换回归无失败；新增覆盖时间审批、重复批准、设备校验、拒绝／取消、重复领取确认、并发防超额和旧凭据升级保留。
- Android：6 项时间计量测试通过，包含前台扣时、暂停、异常退出保留额度、重复暂停、使用中到账、延迟处理关屏事件与旧事件退款边界。
- Android 16 / API 36 独立模拟器：1 项设备测试通过，验证 Android Keystore 加密存储、家长密码、重复发放去重、分钟计量与保存登录。测试数据与原模拟器、真实服务器账号隔离。
- 实际界面流程：零余额打开受限应用出现拦截页；家长批准 1 分钟后手机自动领取，普通积分只扣一次；返回桌面与查看积分小屋不扣时；受限应用使用后归零再次拦截；重启后配置、余额、登录及已授权的拦截服务保留。
- 界面：检查默认约 393 dp 宽度、320 dp 宽度与 1.3 倍字体、640×360 dp 横屏；状态栏与导航栏留出安全区域，内容可以滚动，卡片保留间距。拦截页会随方向、字体和密度重新计算布局。
- 构建：Debug、Release 和 Android Lint 通过，APK 验证 v1/v2 签名通过；与 0.1.0 使用相同签名，可覆盖安装。
- 云端：新后端校验后部署，原有数据数量与余额核对一致，公网 HTTPS 正常校验；升级前冷备份保留在服务器并保存了一份到本机私人目录。

真实荣耀 Play4T Pro 暂时未连接；鸿蒙的后台保活、设备管理员交互和 Device Owner 防卸载分支尚未在该真机上验证。本次未重置或配置任何真实手机的整机管理。
