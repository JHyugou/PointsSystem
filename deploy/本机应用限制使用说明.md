# 本机应用限制与时间奖励（0.2.0）

## 第一次在孩子手机上设置

1. 家长和孩子的手机都覆盖安装新版 APK，保留原有应用数据。
2. 在孩子手机上登录孩子账号。打开右上角 ☰ → **本机应用限制**。
3. 由家长填写已关联这个孩子的家长邮箱、家长登录密码，以及新的**本机家长密码**。本机密码至少 6 位，与孩子的登录密码分开保管。
4. 点击 **家长设置**，输入本机密码。点击 **开启／检查应用拦截权限**，在系统无障碍设置中开启“积分小屋 · 本机应用限制”。从系统设置返回后再次输入家长密码。
5. 选择要限制的应用，开启应用限制，保存。电话、桌面、系统设置和积分小屋不能加入受限列表。
6. 可开启**基础卸载防护**，按系统提示启用设备管理员。这个模式会增加卸载前的停用步骤，无法提供绝对防卸载。

安装在 Android 13 或更高系统上时，系统可能要求先在“应用信息 → 右上角菜单”允许受限设置，再允许无障碍服务；请按实际系统提示操作。荣耀／华为系统还需在应用启动管理中允许自动启动和后台运行。真实荣耀 Play4T Pro 的兼容性尚未验证。

## 兑换时间

1. 家长在 **兑换 → 添加** 选择 **应用时间**，填写奖励名称、消耗积分和发放分钟数（每次 1～1440 分钟）。
2. 孩子在已绑定手机上申请兑换。申请时不扣分。
3. 家长在兑换页的 **待批准的时间申请** 或 **兑换凭据** 中批准／拒绝。批准时检查当时的积分余额并扣分，积分不足不能批准。
4. 孩子打开积分小屋，时间会自动同步，也可以点击 **领取已批准时间**。所有受限应用共用这个时间余额。重复批准、重复同步或网络重试不会重复扣分或重复发时间。
5. 已到账时间在离线时也能使用。只在受限应用处于前台且屏幕解锁时计时；返回桌面、切到其他应用或锁屏会暂停。没有记录或上传应用使用历史。

时间是独立余额，普通积分不会随使用直接减少。此版每个孩子绑定一台领取时间的手机，一台手机仅绑定一个孩子；时间不跨设备共享。更换手机前请先领取旧手机已批准但未领取的时间；旧手机已有余额不会迁移或远程清除。

## 密码与解除

更改受限应用、解除应用限制、解除卸载防护、修改本机密码、退出账号和更换服务器均需要家长密码。家长设置离开页面后自动锁定，最长保留两分钟。忘记本机密码可用**已关联家长的登录账号**重设，保留原有余额。

## 防卸载能达到什么程度

| 状态 | 实际效果 |
| --- | --- |
| 普通应用＋无障碍权限 | 应用运行时拦截选中的应用；系统权限被关闭或应用被强制结束后不能保证继续拦截 |
| 基础设备管理员 | 卸载前需要停用管理员；孩子仍可能在系统设置中停用、清除数据或卸载 |
| 整机管理（Device Owner） | Android 系统级卸载保护和应用暂停；Android 11 起还可禁止本应用被强制停止或清除数据 |

应用会显示实际级别。**家长密码保护本应用内部设置，无法替代 Android 的整机管理权限。** 普通安装不能一键成为整机管理，通常需要新设备或恢复出厂状态；本次没有重置任何手机，也没有给真实手机配置整机管理。

整机管理仅适合后续确认支持的专用儿童设备。时间为零时系统可能直接显示“应用已暂停”，需先打开积分小屋兑换并领取。家长在应用中解除整机管理时会看到单独确认，解除后恢复整机管理需重新配置设备。此分支的真机行为仍待核对。

为避免重启获得额外时间，应用先保存最多五秒的使用额度，再放行应用；正常离开应用会退回未用部分。进程意外中断或强制关机时，最多损失这五秒，不会恢复已经消耗的时间。清除应用数据或卸载会丢失本地设置和余额，重新安装不能自动补发已领取时间。

## 建议真机验证

先用少量积分兑换 1～2 分钟，确认到账、仅前台扣时、锁屏暂停、归零拦截和家长密码，再确认重启手机后的权限与余额。孩子的电话和紧急联系始终保留。

## 界面与图标

新版使用系统安全区域避开状态栏、刘海和导航栏，并随键盘调整可视区域；不同宽度采用适合的边距，宽屏内容居中，内容过长可以滚动。积分／兑换卡片有独立间距，标题与菜单会分配空间。图标改为绿色小屋与金色星星，提供普通、自适应、圆形及主题图标资源。
